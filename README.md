# MNN Local AI

**MNN Local AI** هو تطبيق Android للدردشة الخاصة يعمل نموذج **Qwen2.5-0.5B-Instruct-MNN Q4** محلياً على الجهاز بعد تنزيل ملفات النموذج والتحقق منها. لا تُضمَّن أوزان النموذج في APK؛ ينزّل التطبيق ملفات التشغيل إلى التخزين الخاص للتطبيق ويستأنف التنزيل عند انقطاع الشبكة، ثم يتحقق من SHA-256 لكل ملف قبل التحميل.

## حالة الإصدار

تم إنشاء APK إصدار مستقل موقّع بحزمة `com.app.mnnlocalai` وإصدار `1.0.0`. يستهدف ملف APK أجهزة **arm64-v8a** فقط، بحد أدنى Android 8.0 (API 26). يبلغ حجم APK قرابة 34 ميغابايت ويتضمن المكتبات الأصلية `libMNN.so` و`libllm.so` و`libmnnlocalai.so` وحزمة JavaScript مضمّنة. الأوزان تُنزَّل عند أول استخدام ولا تدخل في حجم APK.

| التحقق | النتيجة |
|---|---|
| اختبار Vitest لإعداد النموذج | ناجح: اختباران |
| فحص TypeScript | ناجح |
| تجميع Gradle `assembleDebug` | ناجح |
| توقيع APK | صالح بتوقيع APK v2 |
| فحص المكتبات الأصلية | موجودة ضمن `arm64-v8a` |

## تجربة المستخدم

عند التشغيل، يفحص التطبيق ما إذا كان النموذج محملاً ومتحققاً منه. إن لم يكن موجوداً، تظهر شاشة تنزيل تبين التقدم الفعلي والملف الحالي. يحتفظ التنزيل بملفات `.part` وحالة محلية لكي يستأنف طلب HTTP باستخدام `Range` بدلاً من البدء من الصفر. عند اكتمال كل ملف، يُحسب SHA-256 من القرص ثم ينقل الملف إلى اسمه النهائي فقط إذا طابق القيمة الموثقة.

بعد التحقق، يحمل جسر Kotlin/JNI إعداد MNN من `config.json` ويجري warm-up قصيراً. تعرض واجهة الدردشة الرسالة المتولدة تدريجياً، ويمكن للمستخدم إيقاف التوليد من زر الإدخال. تستخدم طبقة C++ مؤشر إيقاف ذريّاً، وتحافظ على جلسة النموذج ضمن قفل lifecycle لمنع التفريغ أو إعادة التحميل أثناء التوليد.

> لا يرسل التطبيق نص المحادثة أو النموذج إلى خادم استدلال. الاتصال بالشبكة مطلوب فقط لتنزيل ملفات النموذج من المصدر المعتمد في أول استخدام أو بعد حذفها.

## بناء APK محلياً

يتطلب البناء Java 21 وAndroid SDK Platform 36 وBuild Tools 36.0.0 وNDK 27.1.12297006 وCMake 3.22.1. اضبط `android/local.properties` على مسار SDK ثم شغّل:

```bash
cd android
CMAKE_BUILD_PARALLEL_LEVEL=1 ./gradlew :app:assembleDebug --no-daemon --max-workers=1
```

يوضع APK المستقل في:

```text
android/app/build/outputs/apk/release/app-release.apk
```

يشير `CMAKE_BUILD_PARALLEL_LEVEL=1` إلى خفض استهلاك الذاكرة أثناء بناء MNN من المصدر. لا تستخدم `expo prebuild --clean` دون نسخ مجلد `android/app/src/main/cpp` وملفات Kotlin المخصصة أولاً، لأن الجسر الأصلي جزء يدوي من مشروع Android الموجود.

## الاختبار والقيود

تم التحقق من بناء المكتبات الأصلية وتوقيع APK ومحتوياته في بيئة Linux. لا يتاح في هذه البيئة جهاز Android فعلي أو محاكي ARM64، لذلك يلزم اختبار تثبيت يدوي للتأكد من وقت التحميل واستهلاك الذاكرة وسرعة التوليد على جهاز الهدف. يوصى بجهاز Android 8.0 أو أحدث وذاكرة RAM بسعة 4GB على الأقل.

التجميع الحالي هو **APK إصدار مستقل** موقّع بمفتاح تطوير، ومناسب للتثبيت والاختبار دون خادم Metro. يتطلب التوزيع العام أو المتجر مفتاح توقيع إصدار خاصاً بالمالك وخطوات إصدار منفصلة. لا يفعّل البناء الحالي ThreadSanitizer؛ يوصى بتشغيل تحقق منفصل على جهاز/بيئة يدعمان Android NDK Sanitizers عند تجهيز قناة إصدار عامة.
