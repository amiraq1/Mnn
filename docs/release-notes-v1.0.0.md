# MNN Local AI 1.0.0

يتضمن هذا الإصدار الأولي دردشة عربية محلية فوق محرك MNN ونموذج Qwen2.5-0.5B-Instruct-MNN Q4. ينزّل التطبيق النموذج عند أول استخدام، ويدعم الاستئناف عبر HTTP Range requests، ويتحقق من SHA-256 لكل ملف قبل تحميله.

يتضمن APK جسر Kotlin/JNI للتوليد المتدفق، وإيقاف التوليد، وwarm-up، ولوحة لإدارة تفاصيل النموذج وحذفه. لا تضم الحزمة الأوزان؛ يظل حجم التنزيل الأولي للنموذج منفصلاً عن APK.

| التوقيع | إصدار مستقل، موقّع بمفتاح تطوير ومتحقق منه باستخدام APK Signature Scheme v2 |
