# MNN Local AI 1.0.1

يضيف هذا التحديث قياسات عملية مباشرة إلى شاشة **تفاصيل النموذج** بعد كل استجابة محلية. يعرض التطبيق زمن التوليد الكامل، وعدد خطوات التوليد، ومعدل الخطوات في الثانية، وحالة الإيقاف. كما يعرض لقطة حالية من ذاكرة عملية التطبيق باستخدام PSS، والجزء المنسوب للذاكرة الأصلية، واستخدام Java heap.

تعرض القيم «غير متاح بعد» قبل أول توليد ناجح، وتُحدّث عند فتح شاشة التفاصيل وبعد انتهاء الاستجابة. تقيس الأرقام الجهاز الفعلي الذي يعمل عليه النموذج، لذا تختلف باختلاف الجهاز وطول المطالبة وحالة النموذج.

| القياس | المصدر المحلي |
|---|---|
| زمن التوليد | ساعة أحادية في طبقة JNI تشمل دورة الاستجابة والتوليد |
| خطوات التوليد | خطوات `generate(1)` المنفذة خلال آخر استجابة |
| معدل التوليد | خطوات آخر استجابة مقسومة على زمنها |
| PSS والذاكرة الأصلية | `Debug.MemoryInfo` لعملية Android الحالية |
| Java heap | `Runtime` لعملية التطبيق الحالية |

لا يغيّر التحديث مصدر النموذج أو يرسل قياسات الاستخدام إلى أي خدمة خارج الجهاز.
