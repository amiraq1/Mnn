# MNN Local AI 1.3.0

يضيف هذا الإصدار تحكمًا يدويًا بتنزيلات نماذج **MNN** و**GGUF**. أثناء نقل الملف يظهر زر **إيقاف التنزيل مؤقتًا**؛ يحتفظ التطبيق بالملف الجزئي ويغلق اتصال HTTP الحالي. عند اختيار **استئناف التنزيل** يتابع التطبيق من آخر بايت تم حفظه عبر طلب HTTP Range، ثم يستمر في التحقق المعتاد من SHA-256 وترويسة GGUF.

| المؤشر | طريقة العرض |
|---|---|
| سرعة النقل | معدل آخر عينة نقل فعلية، بوحدة مناسبة في الثانية. |
| الوقت المتبقي | تقدير ناتج من البايتات المتبقية وسرعة العينة الحالية؛ يظهر «يُحسب…» إلى أن تتوافر عينة كافية. |
| الإيقاف المؤقت | متاح أثناء نقل البيانات فقط، وليس خلال مرحلة التحقق من سلامة الملف. |
| الاستئناف | يعيد استخدام الملف الجزئي المحلي ويطلب النطاق المتبقي من المصدر. |

لا تتغير متطلبات Android أو معمارية APK: Android 8.0+ (API 26) وarm64-v8a.
