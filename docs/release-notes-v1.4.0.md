# MNN Local AI 1.4.0

يضيف هذا الإصدار طبقة إدارة محلية لتنزيلات النماذج داخل التطبيق، دون الحاجة إلى خادم خارجي أو حساب مستخدم.

| الميزة | السلوك |
|---|---|
| إشعار الإكمال | يرسل التطبيق إشعار Android محليًا بعد تنزيل النموذج والتحقق من سلامة ملفاته وتثبيته. يمكن تعطيل الإشعار من شاشة إدارة التنزيلات. |
| حد الشبكة الخلوية | يمكن اختيار دون حد أو 512 ك.ب/ث أو 1 م.ب/ث أو 2 م.ب/ث. لا يطبق الحد إلا عندما تكون الشبكة النشطة خلوية. |
| سجل التنزيلات | يحفظ آخر 16 نتيجة محليًا، ويعرض اسم النموذج والتاريخ والحجم والزمن والسرعة المتوسطة وحالة الاكتمال أو الإيقاف أو الخطأ. |

يبقى الإيقاف والاستئناف عبر HTTP Range متاحين، وتستمر عملية التحقق من SHA-256 لنماذج MNN وفحص ملف GGUF قبل اعتماد النموذج محليًا.
